Por que você precisa do DucksVantage?

Quem usa Lenovo Legion, LOQ ou IdeaPad no Linux conhece o dilema: ficar sem controle de ventoinhas e bateria ou sofrer com gambiarras.

O PESADELO NO WINDOWS

Lenovo Vantage Oficial

Feito para empurrar assinaturas, anúncios de antivírus e telemetria pesada.

  • ✕ Consome 700MB a 1.2 GB de RAM
  • ✕ 6 daemons rodando em background
  • ✕ Banners de propaganda e garantia
  • ✕ Incompatível com distribuições Linux
A GAMBIARRA TRADICIONAL

Scripts Soltos no GitHub

Comandos bash avulsos que exigem senha sudo toda hora e quebram no primeiro update.

  • ✕ Sem interface gráfica nem medidores
  • ✕ Sem feedback visual do Fn + Q (OSD)
  • ✕ Pede senha root a cada troca de modo
  • ✕ Não detecta estado de repouso da GPU
A SOLUÇÃO DEFINITIVA

DucksVantage 2.0

Engenharia reversa limpa em Python + PyQt6 conversando direto com o kernel Linux.

  • ✔ Apenas ~35 MB de consumo de memória
  • ✔ OSD flutuante translúcido para Fn + Q
  • ✔ Suporte nativo ao 4º perfil: Max-Power
  • ✔ Regras UDEV automáticas (Zero Sudo)
  • ✔ 100% Código Aberto e Zero Telemetria
ENGENHARIA DE PONTA

Construído para Entusiastas de Linux

Sem invencionice. Cada linha de código do DucksVantage foi pensada para extrair o máximo do hardware com a menor pegada de recursos possível.

Destravamento do Perfil Oculto "Max-Power"

No Windows, o Vantage libera um quarto nível de rotação de ventoinhas e watts de EC no Legion Zone. No Linux, a maioria das ferramentas ignora isso. O DucksVantage detecta automaticamente o suporte no driver lenovo-wmi-gamezone e no CachyOS / Linux 6.12+, inserindo o modo Max-Power na rotação direta do Fn + Q.

/sys/firmware/acpi/platform_profile_choices -> [low-power balanced performance max-power]

Pop-up OSD sem Roubar Foco

Construído com flags especiais de janela Qt (WindowDoesNotAcceptFocus). Ao apertar Fn + Q no meio de uma partida de CS2, Dota 2 ou Cyberpunk, o pop-up aparece e desvanece sem minimizar o jogo e sem roubar o mouse.

Auto-Switching por Jogo

Monitora processos ativos do Steam Proton, Heroic Games Launcher, Lutris e Gamescope. Abriu o jogo: ativa Max-Power e governor performance. Fechou o jogo: devolve para balanced ou low-power.

Battery Health Historian

Não fique no escuro quanto à saúde das células. O DucksVantage grava snapshots da capacidade máxima real (energy_full) comparada à capacidade de projeto de fábrica (energy_full_design em Wh) e plota gráficos de degradação.

Aproveitamento da Tecla Copilot (F23)

A Lenovo colocou uma tecla Copilot inútil no seu teclado? O DucksVantage intercepta o sinal de hardware F23 e permite que você a transforme em: Mudo do Microfone no PipeWire, Gatilho do Modo Viagem ou Atalho para Max-Power.

Modo Viagem em 1 Clique (Até +4 Horas de Bateria)

Vai desconectar da tomada e precisa que a bateria dure a viagem toda? O botão Modo Viagem aciona em sequência: trava a carga em 80%, força suspensão D3cold na GPU NVIDIA, corta o Turbo Boost da CPU, define o governor para powersave, limita TDP PL1 para 15W e apaga o LED do teclado.

GPU NVIDIA -> D3cold | CPU Turbo -> Disabled | RAPL PL1 -> 15W | Backlight -> OFF

Zero Sudo / UDEV Automatizado

Chega de digitar sua senha de administrador para trocar o modo da ventoinha. Nosso instalador configura regras seguras em /etc/udev/rules.d/99-ducksvantage.rules concedendo permissão de escrita ao seu usuário nos caminhos ACPI.

INSTALAÇÃO EM 1 MINUTO

Instale na Sua Distro Favorita

O DucksVantage vem com instalador multi-distro que configura os ícones do menu, bandeja do sistema e regras de permissão UDEV automaticamente.

Instale as dependências via pacman e execute o script instalador:

sudo pacman -S python-pyqt6 python-psutil python-pynvml
sudo ./install.sh

Dica: Você também pode empacotar como pacote nativo do Arch via cd packaging && makepkg -si.

Para Ubuntu 22.04+, Debian 12+, Linux Mint ou Pop!_OS:

sudo apt update
sudo apt install python3-pyqt6 python3-psutil python3-pynvml policykit-1
sudo ./install.sh

Para Fedora 39/40, Nobara ou RHEL 9:

sudo dnf install python3-pyqt6 python3-psutil python3-pynvml polkit
sudo ./install.sh

Clone o repositório e rode diretamente sem instalar no sistema:

git clone https://github.com/Patopatetico2-lab/DucksVantage.git
cd DucksVantage
pip install -r requirements.txt
python3 main.py --install-udev
python3 main.py
TIRE SUAS DÚVIDAS

Perguntas Frequentes

O DucksVantage funciona em sessões Wayland (KDE Plasma e GNOME)?

▼

Sim! O pop-up OSD e a interface gráfica foram desenvolvidos especificamente com flags de janela Qt compatíveis com Wayland e X11. O overlay translúcido não aceita foco (WindowDoesNotAcceptFocus) e não minimiza jogos rodando em tela cheia via Gamescope, Proton ou Wine.

Preciso abrir o programa como `sudo`?

▼

Não! O script install.sh instala automaticamente as regras de permissão UDEV (/etc/udev/rules.d/99-ducksvantage.rules). Isso permite que o seu usuário comum controle perfis ACPI, limites de bateria e TDP sem pedir senha root a cada clique.

Existe risco de danificar a bateria ou o hardware?

▼

Nenhum. O DucksVantage não faz overclock inseguro ou gravações brutas de memória. Ele utiliza exclusivamente as interfaces oficiais expostas pelo kernel Linux (ideapad_acpi, platform_profile e RAPL), as mesmas que o firmware da própria Lenovo foi projetado para responder.

Como funciona o Modo de Conservação de 80%?

▼

Quando ativado, ele instrui o Controlador Embarcado (EC) do notebook a suspender o carregamento elétrico das células de lítio quando a carga atinge 75–80%. Dessa forma, o notebook passa a ser alimentado diretamente pela fonte de energia, eliminando a degradação química por sobretensão.

O DucksVantage fica rodando na bandeja do sistema (tray icon)?

▼

Sim! Ele fica discretamente na bandeja do sistema ao fechar a janela principal, com um menu rápido para alternar perfis térmicos, Modo Viagem e sair. Consumindo em média menos de 35 MB de RAM em repouso.
